# Toán học — Trung học cơ sở (lớp 6–9)

[← Môn Toán học](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| ước số | divisor | Ước của số nguyên a là số nguyên d khác 0 sao cho a chia hết cho d. |
| bội số | multiple | Số nhận được khi nhân một số với số nguyên. |
| số nguyên tố | prime number | Số tự nhiên lớn hơn 1 chỉ có hai ước dương là 1 và chính nó. |
| giá trị tuyệt đối | absolute value | Khoảng cách của một số tới 0 trên trục số. |
| tỉ lệ thức | proportion | Đẳng thức giữa hai tỉ số. |
| biến số | variable | Ký hiệu đại diện cho giá trị có thể thay đổi hoặc chưa biết. |
| biểu thức đại số | algebraic expression | Biểu thức gồm số, biến và phép toán. |
| phương trình | equation | Đẳng thức chứa một hoặc nhiều ẩn cần tìm. |
| bất phương trình | inequality | Mệnh đề so sánh biểu thức bằng dấu lớn hơn hoặc nhỏ hơn. |
| hàm số | function | Quy tắc gán mỗi giá trị đầu vào hợp lệ đúng một đầu ra. |
| tam giác đồng dạng | similar triangles | Hai tam giác có góc tương ứng bằng nhau và cạnh tương ứng tỉ lệ. |
| định lý Pythagoras | Pythagorean theorem | Trong tam giác vuông, bình phương cạnh huyền bằng tổng bình phương hai cạnh góc vuông. |
| tập hợp | set | Một nhóm đối tượng được xác định rõ về tư cách phần tử. |
| ước chung lớn nhất | greatest common divisor | Ước dương lớn nhất cùng chia hết các số nguyên đang xét. |
| bội chung nhỏ nhất | least common multiple | Bội dương nhỏ nhất chung của các số nguyên khác 0 đang xét. |
| căn bậc hai số học | principal square root | Số không âm mà bình phương bằng số không âm đã cho. |
| hệ phương trình | system of equations | Nhiều phương trình cần được thỏa mãn đồng thời. |
| định lý Thales | intercept theorem / basic proportionality theorem | Định lý về các đoạn thẳng tỉ lệ khi những đường thẳng song song cắt hai đường thẳng khác. |
| đường tròn | circle | Tập hợp các điểm trong mặt phẳng cách đều một điểm cố định. |
| xác suất | probability | Đại lượng mô tả mức độ có thể xảy ra của một biến cố trong mô hình ngẫu nhiên. |
| số hữu tỉ | rational number | Số có thể viết dưới dạng tỉ số hai số nguyên với mẫu khác không. |
| số vô tỉ | irrational number | Số thực không thể viết thành tỉ số hai số nguyên. |
| số thực | real number | Số nằm trên trục số, gồm các số hữu tỉ và vô tỉ. |
| phân tích nhân tử | factorization | Viết biểu thức hoặc số thành tích các nhân tử. |
| phân thức đại số | rational algebraic expression | Biểu thức có dạng thương hai đa thức với mẫu khác đa thức không. |
| phương trình bậc hai | quadratic equation | Phương trình dạng ax² + bx + c = 0 với a khác 0. |
| hệ trục tọa độ | coordinate system | Hệ trục dùng xác định vị trí của điểm bằng bộ tọa độ. |
| định lý | theorem | Mệnh đề toán học đã được chứng minh từ giả thiết và các kết quả chấp nhận. |
| chứng minh | mathematical proof | Chuỗi lập luận hợp lệ xác lập tính đúng của mệnh đề. |
| góc nội tiếp | inscribed angle | Góc có đỉnh nằm trên đường tròn và hai cạnh chứa hai dây cung. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
