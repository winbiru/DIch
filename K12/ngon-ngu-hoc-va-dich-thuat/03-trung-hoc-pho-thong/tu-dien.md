# Ngôn ngữ học và dịch thuật — Trung học phổ thông (lớp 10–12)

[← Môn Ngôn ngữ học và dịch thuật](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| ngôn ngữ học đối chiếu | contrastive linguistics | Ngành so sánh hệ thống hai hay nhiều ngôn ngữ để nhận ra khác biệt và tương đồng. |
| ngôn ngữ học lịch sử | historical linguistics | Ngành nghiên cứu biến đổi của ngôn ngữ qua thời gian. |
| ngôn ngữ học xã hội | sociolinguistics | Ngành nghiên cứu mối quan hệ giữa ngôn ngữ và xã hội. |
| ngữ dụng học | pragmatics | Ngành nghiên cứu cách người nói tạo và người nghe suy ra ý nghĩa trong ngữ cảnh. |
| ngôn hành | speech act | Hành động xã hội được thực hiện thông qua phát ngôn như yêu cầu hoặc hứa hẹn. |
| hàm ý hội thoại | conversational implicature | Ý được suy ra từ lời nói nhờ ngữ cảnh và giả định hợp tác giao tiếp. |
| phân tích diễn ngôn | discourse analysis | Nghiên cứu việc dùng ngôn ngữ trong văn bản và tương tác xã hội. |
| liên kết văn bản | cohesion | Các phương tiện ngôn ngữ kết nối những phần của văn bản. |
| mạch lạc văn bản | coherence | Sự thống nhất ý nghĩa và tổ chức logic của văn bản. |
| đơn vị dịch | translation unit | Đoạn hoặc thành phần được xem như một đơn vị xử lý trong hoạt động dịch. |
| tương đương dịch thuật | translation equivalence | Quan hệ tương ứng về nghĩa hoặc chức năng giữa biểu thức nguồn và đích. |
| dịch sát nghĩa | literal translation | Cách dịch bám sát cấu trúc hoặc từ ngữ nguồn trong phạm vi có thể hiểu. |
| dịch theo ý | sense-for-sense translation | Cách chuyển tải nội dung trọng tâm bằng diễn đạt tự nhiên của ngôn ngữ đích. |
| chuyển ngữ | language transfer / translation | Việc chuyển nội dung hoặc hình thức biểu đạt từ ngôn ngữ này sang ngôn ngữ khác. |
| phiên âm | phonetic transcription | Biểu diễn âm thanh lời nói bằng hệ ký hiệu phiên âm. |
| chuyển tự | transliteration | Chuyển văn bản từ hệ chữ viết này sang hệ chữ viết khác theo quy tắc. |
| bản địa hóa | localization | Điều chỉnh sản phẩm, nội dung phù hợp ngôn ngữ và bối cảnh văn hóa của thị trường đích. |
| thuật ngữ học | terminology studies | Ngành nghiên cứu thuật ngữ, khái niệm và cách đặt tên trong lĩnh vực chuyên môn. |
| chuẩn hóa thuật ngữ | terminology standardization | Thống nhất dạng thuật ngữ và cách dùng trong một lĩnh vực dựa trên tiêu chí. |
| ngữ liệu | corpus | Tập hợp văn bản hoặc lời nói được thu thập có hệ thống để nghiên cứu ngôn ngữ. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
