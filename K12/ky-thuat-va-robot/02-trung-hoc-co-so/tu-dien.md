# Kỹ thuật và robot — Trung học cơ sở (lớp 6–9)

[← Môn Kỹ thuật và robot](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| quy trình thiết kế kỹ thuật | engineering design process | Chuỗi bước xác định vấn đề, đề xuất, thử nghiệm và cải tiến giải pháp kỹ thuật. |
| yêu cầu kỹ thuật | technical requirement | Đặc điểm hoặc giới hạn mà sản phẩm phải đáp ứng. |
| thông số kỹ thuật | technical specification | Tập giá trị và yêu cầu mô tả chức năng hoặc đặc tính của hệ thống. |
| sơ đồ khối | block diagram | Sơ đồ biểu diễn hệ qua các khối chức năng và quan hệ kết nối. |
| đầu vào | input | Tín hiệu, dữ liệu hoặc nguồn vật chất đi vào hệ thống. |
| đầu ra | output | Kết quả, tín hiệu hoặc vật chất hệ thống tạo ra. |
| mạch điện | electrical circuit | Đường kết nối các phần tử để dẫn và điều khiển dòng điện. |
| vi điều khiển | microcontroller | Mạch tích hợp có bộ xử lý, bộ nhớ và giao tiếp ngoại vi để điều khiển thiết bị. |
| bộ truyền động | actuator | Thiết bị biến tín hiệu điều khiển thành tác động vật lý hoặc chuyển động. |
| động cơ servo | servo motor | Cơ cấu truyền động có phản hồi hoặc điều khiển vị trí, tốc độ hay mô-men. |
| cảm biến siêu âm | ultrasonic sensor | Cảm biến sử dụng sóng siêu âm để đo khoảng cách hoặc phát hiện vật. |
| cảm biến ánh sáng | light sensor | Thiết bị nhận biết cường độ hoặc đặc tính ánh sáng. |
| đường dẫn tín hiệu | signal path | Đường mà thông tin tín hiệu truyền qua các phần tử của hệ thống. |
| phản hồi | feedback | Việc đưa thông tin kết quả trở về để điều chỉnh hoạt động hệ thống. |
| điều khiển vòng hở | open-loop control | Điều khiển không dùng phản hồi của đầu ra để điều chỉnh lệnh. |
| điều khiển vòng kín | closed-loop control | Điều khiển dùng phản hồi đầu ra để điều chỉnh sai lệch. |
| lập trình robot | robot programming | Viết chỉ dẫn cho robot nhận thông tin và thực hiện hành động. |
| mô phỏng | simulation | Dùng mô hình tái hiện hoạt động của hệ thống để nghiên cứu hoặc thử nghiệm. |
| hiệu chuẩn | calibration | Đối chiếu hoặc điều chỉnh phép đo theo chuẩn tham chiếu thích hợp. |
| dung sai | tolerance | Khoảng sai lệch cho phép so với thông số thiết kế. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
