# Tin học — Trung học phổ thông (lớp 10–12)

[← Môn Tin học](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| độ phức tạp thuật toán | algorithmic complexity | Mức tài nguyên mà thuật toán sử dụng theo kích thước đầu vào. |
| cấu trúc dữ liệu | data structure | Cách tổ chức dữ liệu hỗ trợ truy cập và thao tác hiệu quả. |
| ngăn xếp | stack | Cấu trúc dữ liệu thường lấy phần tử vào sau ra trước. |
| hàng đợi | queue | Cấu trúc dữ liệu thường lấy phần tử vào trước ra trước. |
| cây nhị phân | binary tree | Cấu trúc cây trong đó mỗi nút có nhiều nhất hai nút con. |
| đồ thị | graph | Mô hình gồm tập đỉnh và tập cạnh nối các đỉnh. |
| lập trình hướng đối tượng | object-oriented programming | Mô hình lập trình tổ chức dữ liệu và hành vi trong các đối tượng. |
| đệ quy | recursion | Cách định nghĩa hoặc giải bài toán thông qua các trường hợp nhỏ hơn cùng dạng. |
| cơ sở dữ liệu | database | Tập hợp dữ liệu được tổ chức để lưu trữ và truy vấn. |
| truy vấn | query | Yêu cầu truy xuất hoặc biến đổi dữ liệu theo điều kiện. |
| khóa chính | primary key | Thuộc tính hoặc tập thuộc tính nhận diện duy nhất mỗi hàng trong bảng quan hệ. |
| mã hóa dữ liệu | encryption | Biến đổi dữ liệu bằng thuật toán và khóa để người không có khóa khó đọc được. |
| băm mật mã | cryptographic hashing | Tính giá trị băm bằng hàm thiết kế cho các tính chất bảo mật nhất định. |
| trí tuệ nhân tạo | artificial intelligence | Lĩnh vực xây dựng hệ thống thực hiện tác vụ đòi hỏi các năng lực trí tuệ. |
| học máy | machine learning | Phương pháp cho hệ thống học mẫu hoặc quy luật từ dữ liệu. |
| mô hình ngôn ngữ | language model | Mô hình ước lượng hoặc tạo chuỗi ngôn ngữ dựa trên ngữ cảnh. |
| điện toán đám mây | cloud computing | Cung cấp tài nguyên tính toán qua mạng theo nhu cầu. |
| giao diện lập trình ứng dụng | application programming interface (API) | Quy ước cho phép các thành phần phần mềm tương tác. |
| phần mềm mã nguồn mở | open-source software | Phần mềm có mã nguồn được cung cấp theo giấy phép cho phép sử dụng, sửa đổi và phân phối theo điều kiện. |
| quản lý phiên bản | version control | Hệ thống theo dõi lịch sử thay đổi của tệp và phối hợp phát triển. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
