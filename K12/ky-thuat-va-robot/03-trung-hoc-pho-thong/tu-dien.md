# Kỹ thuật và robot — Trung học phổ thông (lớp 10–12)

[← Môn Kỹ thuật và robot](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| động học robot | robot kinematics | Nghiên cứu quan hệ hình học giữa cấu hình khớp và vị trí, hướng của robot. |
| động lực học robot | robot dynamics | Nghiên cứu quan hệ lực, mô-men và chuyển động trong hệ robot. |
| bậc tự do | degree of freedom | Số biến độc lập cần để mô tả cấu hình hoặc chuyển động của hệ. |
| đường đi của robot | robot path | Tập vị trí hoặc cấu hình robot dự kiến đi qua. |
| lập kế hoạch quỹ đạo | trajectory planning | Xác định chuyển động của robot theo thời gian với các ràng buộc. |
| định vị | localization | Ước lượng vị trí và hướng của robot trong một hệ tọa độ. |
| lập bản đồ | mapping | Tạo mô hình biểu diễn môi trường xung quanh từ dữ liệu thu thập. |
| định vị và lập bản đồ đồng thời | simultaneous localization and mapping (SLAM) | Phương pháp robot vừa ước lượng vị trí vừa xây dựng bản đồ môi trường. |
| hợp nhất cảm biến | sensor fusion | Kết hợp dữ liệu từ nhiều cảm biến để ước lượng trạng thái chính xác hơn. |
| điều khiển PID | PID control | Phương pháp điều khiển dùng thành phần tỉ lệ, tích phân và vi phân của sai lệch. |
| hệ nhúng | embedded system | Hệ thống máy tính chuyên dụng nằm trong thiết bị để thực hiện chức năng xác định. |
| thời gian thực | real-time system | Tính chất hệ phải đáp ứng ràng buộc thời hạn thực thi ngoài tính đúng kết quả. |
| giao tiếp nối tiếp | serial communication | Truyền dữ liệu tuần tự qua kênh liên lạc. |
| xung điều chế độ rộng | pulse-width modulation (PWM) | Cách điều khiển giá trị trung bình tín hiệu bằng thay đổi độ rộng xung. |
| thiết kế có máy tính hỗ trợ | computer-aided design (CAD) | Sử dụng phần mềm để dựng và chỉnh sửa thiết kế kỹ thuật. |
| in ba chiều | 3D printing | Chế tạo vật thể bằng cách bồi đắp vật liệu theo lớp từ mô hình số. |
| mạng nơ-ron nhân tạo | artificial neural network | Mô hình học máy gồm các đơn vị xử lý liên kết với tham số có thể điều chỉnh. |
| thị giác máy tính | computer vision | Lĩnh vực xử lý và diễn giải thông tin từ hình ảnh hoặc video bằng máy tính. |
| robot cộng tác | collaborative robot | Robot được thiết kế để có thể hoạt động gần hoặc cùng con người theo yêu cầu an toàn. |
| đánh giá rủi ro kỹ thuật | engineering risk assessment | Phân tích khả năng và hậu quả sự cố để lựa chọn biện pháp giảm rủi ro. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
