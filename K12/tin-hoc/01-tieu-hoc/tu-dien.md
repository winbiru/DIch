# Tin học — Tiểu học (lớp 1–5)

[← Môn Tin học](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| máy tính | computer | Thiết bị điện tử xử lý dữ liệu theo chương trình. |
| bàn phím | keyboard | Thiết bị dùng nhập ký tự và lệnh vào máy tính. |
| chuột máy tính | computer mouse | Thiết bị trỏ để điều khiển con trỏ trên màn hình. |
| màn hình | display / monitor | Thiết bị hiển thị thông tin từ máy tính. |
| tệp | file | Đơn vị lưu trữ dữ liệu được đặt tên trong hệ thống tệp. |
| thư mục | folder / directory | Vùng tổ chức chứa tệp và các thư mục con. |
| phần mềm | software | Tập hợp chương trình và dữ liệu liên quan thực hiện chức năng trên máy tính. |
| phần cứng | hardware | Các thành phần vật lý của một hệ thống máy tính. |
| dữ liệu | data | Thông tin được biểu diễn để lưu trữ, truyền hoặc xử lý. |
| thông tin | information | Nội dung có ý nghĩa đối với người tiếp nhận hoặc một quá trình xử lý. |
| mật khẩu | password | Chuỗi bí mật dùng chứng minh quyền truy cập. |
| trình duyệt web | web browser | Phần mềm truy cập và hiển thị nội dung trên World Wide Web. |
| đường liên kết | hyperlink | Thành phần có thể chọn để chuyển đến tài nguyên hoặc vị trí khác. |
| công cụ tìm kiếm | search engine | Dịch vụ lập chỉ mục và tìm nội dung theo truy vấn. |
| lưu tệp | save file | Thao tác ghi nội dung tài liệu hoặc dữ liệu vào nơi lưu trữ. |
| quyền riêng tư | privacy | Quyền và khả năng kiểm soát việc thu thập, sử dụng thông tin cá nhân. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
