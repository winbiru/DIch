# Mỹ thuật — Tiểu học (lớp 1–5)

[← Môn Mỹ thuật](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| đường nét | line | Dấu vạch kéo dài làm thành yếu tố tạo hình. |
| hình | shape | Mảng có ranh giới trên mặt phẳng. |
| khối | form / volume | Yếu tố hình thể có ba chiều trong không gian. |
| màu sắc | color | Đặc tính thị giác của ánh sáng được bề mặt phản xạ hoặc phát ra. |
| màu cơ bản | primary color | Màu gốc được chọn trong một hệ phối màu để tạo các màu khác. |
| màu bổ túc | complementary color | Cặp màu đối diện nhau trên một vòng màu xác định. |
| đậm nhạt | value / lightness | Mức độ sáng tối của màu hoặc sắc độ. |
| bố cục | composition | Cách sắp xếp các yếu tố thị giác trong tác phẩm. |
| tranh vẽ | painting / drawing | Tác phẩm tạo hình trên bề mặt bằng chất liệu phù hợp. |
| chân dung | portrait | Hình ảnh thể hiện diện mạo hoặc tính cách một người. |
| phong cảnh | landscape | Tác phẩm tạo hình mô tả cảnh thiên nhiên hoặc môi trường. |
| hoa văn | ornament / pattern | Hình hoặc mô típ trang trí được lặp lại hay tổ chức có chủ đích. |
| nặn tượng | modeling | Tạo hình ba chiều bằng vật liệu mềm như đất sét. |
| thủ công | handicraft | Sản phẩm hoặc hoạt động làm đồ vật chủ yếu bằng thao tác thủ công. |
| trưng bày | exhibition / display | Sắp đặt tác phẩm để người khác xem và thưởng thức. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
