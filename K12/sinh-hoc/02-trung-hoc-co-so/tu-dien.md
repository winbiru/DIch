# Sinh học — Trung học cơ sở (lớp 6–9)

[← Môn Sinh học](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| tế bào | cell | Đơn vị cấu trúc và chức năng cơ bản của sinh vật. |
| màng sinh chất | plasma membrane | Lớp bao tế bào điều tiết nhiều trao đổi chất. |
| nhân tế bào | cell nucleus | Bào quan ở tế bào nhân thực thường chứa phần lớn vật chất di truyền. |
| mô | tissue | Nhóm tế bào và chất gian bào cùng thực hiện chức năng. |
| cơ quan | organ | Bộ phận gồm các mô phối hợp thực hiện nhiệm vụ sinh học. |
| quang hợp | photosynthesis | Quá trình sinh vật dùng năng lượng ánh sáng để tổng hợp chất hữu cơ. |
| hô hấp tế bào | cellular respiration | Các quá trình chuyển hóa tạo ATP từ chất dinh dưỡng. |
| nhiễm sắc thể | chromosome | Cấu trúc chứa DNA kết hợp protein mang thông tin di truyền. |
| di truyền | heredity | Sự truyền đặc điểm sinh học qua các thế hệ. |
| hệ sinh thái | ecosystem | Hệ gồm quần xã sinh vật và môi trường vô sinh tương tác. |
| quần thể sinh vật | population | Nhóm cá thể cùng loài ở một khu vực, thời điểm xác định và có khả năng sinh sản với nhau. |
| đa dạng sinh học | biodiversity | Sự phong phú của gen, loài và hệ sinh thái. |
| lục lạp | chloroplast | Bào quan quang hợp của thực vật và nhiều nhóm tảo. |
| ty thể | mitochondrion | Bào quan tham gia sản xuất phần lớn ATP ở nhiều tế bào nhân thực. |
| vi sinh vật | microorganism | Sinh vật hoặc dạng sống có kích thước vi mô, thường cần kính hiển vi để quan sát. |
| vi khuẩn | bacterium | Sinh vật đơn bào thuộc nhóm sinh vật nhân sơ Bacteria. |
| nấm | fungus | Sinh vật nhân thực dị dưỡng thuộc giới Nấm. |
| phân bào | cell division | Quá trình một tế bào phân chia để tạo các tế bào con. |
| nguyên phân | mitosis | Quá trình phân chia nhân tế bào nhân thực thường tạo hai nhân có bộ nhiễm sắc thể tương ứng. |
| giảm phân | meiosis | Kiểu phân bào làm giảm số bộ nhiễm sắc thể, tạo tế bào đơn bội trong chu trình sinh sản hữu tính. |
| hệ tuần hoàn | circulatory system | Hệ cơ quan vận chuyển máu hoặc dịch tuần hoàn trong cơ thể động vật. |
| trao đổi chất | metabolism | Tập hợp các phản ứng sinh hóa tạo và sử dụng vật chất, năng lượng trong cơ thể. |
| bào quan | organelle | Cấu trúc chuyên hóa thực hiện chức năng trong tế bào. |
| chất diệp lục | chlorophyll | Nhóm sắc tố hấp thụ ánh sáng tham gia quang hợp. |
| enzyme | enzyme | Chất xúc tác sinh học, thường là protein, làm tăng tốc phản ứng sinh hóa. |
| hormone | hormone | Chất tín hiệu do tế bào tạo ra để điều hòa hoạt động sinh học. |
| trao đổi khí | gas exchange | Quá trình trao đổi khí như oxygen và carbon dioxide giữa cơ thể với môi trường. |
| virus | virus | Tác nhân lây nhiễm có vật chất di truyền và chỉ nhân lên nhờ tế bào chủ. |
| hệ thần kinh | nervous system | Mạng tế bào và cơ quan nhận, xử lý tín hiệu để điều phối hoạt động cơ thể. |
| hệ bài tiết | excretory system | Hệ cơ quan tham gia loại bỏ sản phẩm thải chuyển hóa. |
| mô phân sinh | meristem | Mô thực vật có các tế bào phân chia tạo tế bào mới. |
| cân bằng sinh thái | ecological balance | Trạng thái các thành phần của hệ sinh thái duy trì quan hệ tương đối ổn định và có thể biến đổi. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
