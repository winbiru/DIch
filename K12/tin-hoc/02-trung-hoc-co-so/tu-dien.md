# Tin học — Trung học cơ sở (lớp 6–9)

[← Môn Tin học](../README.md) · [↑ Kho K12](../../README.md)

| Thuật ngữ tiếng Việt | Thuật ngữ tiếng Anh | Giải nghĩa |
| --- | --- | --- |
| thuật toán | algorithm | Dãy bước hữu hạn, rõ ràng để giải quyết một lớp bài toán. |
| biến | variable | Tên gắn với giá trị có thể được tham chiếu và thay đổi theo quy tắc chương trình. |
| hằng số | constant | Giá trị được xác định không thay đổi trong phạm vi đã quy định. |
| kiểu dữ liệu | data type | Quy định tập giá trị và những phép toán hợp lệ đối với dữ liệu. |
| điều kiện | condition | Biểu thức đánh giá đúng hoặc sai để quyết định hành động. |
| vòng lặp | loop | Cấu trúc thực thi lặp lại một khối lệnh. |
| hàm | function | Đơn vị chương trình thực hiện một tác vụ, có thể nhận đầu vào và trả kết quả. |
| mảng | array | Cấu trúc chứa tập phần tử có thể truy cập theo chỉ số. |
| danh sách | list | Cấu trúc dữ liệu biểu diễn dãy phần tử. |
| chuỗi ký tự | string | Dãy ký tự được xử lý như một giá trị. |
| mã nguồn | source code | Văn bản chương trình do con người viết bằng ngôn ngữ lập trình. |
| trình biên dịch | compiler | Chương trình chuyển mã nguồn sang dạng mã đích để chạy hoặc xử lý tiếp. |
| kiểm thử | testing | Hoạt động chạy hoặc phân tích phần mềm để kiểm tra hành vi và phát hiện lỗi. |
| gỡ lỗi | debugging | Quá trình xác định và sửa nguyên nhân gây lỗi chương trình. |
| hệ điều hành | operating system | Phần mềm quản lý tài nguyên máy tính và cung cấp dịch vụ cho chương trình. |
| mạng máy tính | computer network | Tập hợp thiết bị kết nối để trao đổi dữ liệu và chia sẻ tài nguyên. |
| địa chỉ IP | IP address | Địa chỉ logic dùng nhận diện giao diện mạng trong giao thức Internet. |
| giao thức | protocol | Tập hợp quy tắc định dạng và trao đổi thông điệp giữa các hệ thống. |
| mã độc | malware | Phần mềm được tạo để gây hại, xâm nhập hoặc thực hiện hành vi trái phép. |
| sao lưu | backup | Tạo bản sao dữ liệu để có thể khôi phục khi cần. |
| bít | bit | Đơn vị thông tin có thể nhận một trong hai giá trị theo biểu diễn nhị phân. |
| byte | byte | Đơn vị dữ liệu thường gồm tám bít trong máy tính hiện đại. |
| hệ nhị phân | binary numeral system | Hệ đếm cơ số hai dùng các chữ số 0 và 1. |
| thuật toán sắp xếp | sorting algorithm | Thuật toán đặt các phần tử theo một thứ tự quy định. |
| thuật toán tìm kiếm | search algorithm | Thuật toán xác định vị trí hoặc sự tồn tại của dữ liệu thỏa điều kiện. |

Các thuật ngữ thuộc kho dịch thuật/giáo dục; chưa phải API hoặc cú pháp V++.
